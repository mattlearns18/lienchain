## Part A — `/attorney/demo` route gate regression (DEMO-BLOCKING)

The Phase 8 token gate is now applying to `/attorney/demo`, which was meant to be the standalone public-facing attorney walkthrough. Today visiting `https://lienchain.vercel.app/attorney/demo` directly shows:

> 🔒 Access required for demo
> This case requires an invitation from the case operator…

This is the route the landing page CTAs link to. Any investor or attorney clicking through from `/` hits a wall instead of seeing the attorney portal demo.

**Fix:** In whatever route handler renders `AttorneyPortal` for `/attorney/:caseId`, special-case `caseId === 'demo'` to skip the token gate entirely and render the standalone demo case (the hardcoded mock case in `AttorneyPortal.jsx` that predates the Phase 5 multi-clinic flow). The token gate logic from Phase 8 should only apply when `caseId` is a real case in `lienchain:cases` or matches a back-compat-shim seed lien ID.

Pseudocode in `AttorneyPortal.jsx`:

```js
const { caseId } = useParams();

// Special demo route — always renders the standalone showcase, never gated
if (caseId === 'demo') {
  return <FullAttorneyPortal caseId="demo" />;
}

// All other caseIds flow through the Phase 8 token gate
const { isDirectRoute, ... } = useTokenGate(caseId);
// ...
```

## Part E — Recovery Rate chart Y-axis tick formatter

The recharts Y-axis on the "Recovery Rate Over Time" chart is rendering ticks as raw floats: `99.74358974358975%`. The tooltip formatter uses `.toFixed(1)` but the YAxis `tickFormatter` doesn't.

Fix in the chart component:

```jsx
<YAxis
  domain={[0, 'dataMax + 10']}
  tickFormatter={v => `${Math.round(v)}%`}  // was: `${v}%`
/>
```

Round to whole percentages on the axis; keep one decimal in the tooltip.

## Part F — Stray `<span>0%</span>` directly under `<body>`

A bare `<span>0%</span>` is rendering directly inside `<body>`, not a child of any container. Visible via DOM query (`document.body > span` with text `0%`). Rect is empty so it may not be visually obvious, but it's a leak and shows up in any DOM inspection.

Likely a Recharts artifact (stray text node from a chart ResponsiveContainer mount/unmount cycle) or a leaked React render. Run the dashboard with React DevTools open; trace the component tree to find the offending render and clean it up.

## Part G — Phase 9 deferred: success modal "0 TXs on XRPL" final state

The in-flight settlement animation correctly displays "2 TXs on XRPL" (or whatever the success count is), but on the success-complete final state of the modal it reads "0 TXs on XRPL". The successCount that drives the animation copy isn't being carried through to the final-state render.

Fix in `AttorneyPreview.jsx`'s settlement modal: store the count in state at the end of the loop, and read from state instead of recomputing on the success screen. Or wherever the final-state copy is built, source it from the same `payoutResults.filter(r => r.success).length` the animation uses.

## Part H — Phase 9 deferred: fiat receipt prefill initial-load

The Mark Fiat Received modal prefills with the gross settlement amount instead of `netAvailable` when the modal opens on a fresh case (before the operator touches the gross input). After any gross-input interaction, the prefill correctly reads `netAvailable` via the useEffect that syncs to the waterfall result.

Fix: derive the initial prefill value directly from the case's bills + the default fee% (33%) on first render, not from a stale waterfall state. The waterfall calculator is pure — call it once on modal open with the default inputs to get the correct `netAvailable` as the prefill.

## Part I — Phase 8 polish: "Multi" market label tooltip on multi-clinic case parent rows

In the Liens tab, multi-clinic cases show "Multi" in the Market column instead of listing the actual markets involved. When the case is collapsed, the user can't tell which states are represented without expanding the row.

Fix: add a `title` attribute (or a hover tooltip if there's an existing tooltip component) on the "Multi" badge listing the distinct markets, comma-separated:

```jsx
<span title={`Markets: ${[...new Set(clinics.map(c => c.market))].sort().join(', ')}`}>
  Multi
</span>
```

Native `title` is fine — clean fallback, no new component needed.
