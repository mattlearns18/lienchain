## Goal

Enforce the Indiana 20% clinic floor in the settlement waterfall. Math change: any clinic where `market === 'IN'` is guaranteed at least `bill × 0.20` in recovery. Floor is applied **after** pro-rata distribution, with iterative re-distribution when a raise is needed. Mixed cases (IN + non-IN clinics) only protect the IN clinics; non-IN clinics absorb the haircut.

Pure pro-rata stays the rule when no IN clinic is below floor (most common case).

## Where the math lives

`src/pages/AttorneyPortal.jsx` — the case-level waterfall calculator that produces the per-clinic recovery table. Today it does pure pro-rata. Replace that with the algorithm below.

Read `MARKET_INFO.IN.policy.clinicFloorPct` from `src/lib/markets.js` (Commit 1 placed it there as `0.20`). Don't hardcode `0.2` in the waterfall code.

## Algorithm

```
inputs:  netAvailable, clinics (array of { bill, market, ...other })
output:  recoveries (array same length as clinics, with .recovery and .floorApplied)

1. Initialize: every clinic gets a starting `recovery` from pure pro-rata:
       totalBills = sum(c.bill for c in clinics)
       for each c: c.recovery = (c.bill / totalBills) × netAvailable
                   c.floorApplied = false
                   c.fixed = false   // marks clinics whose recovery is finalized

2. Identify IN clinics not yet fixed: { c : c.market === 'IN' && !c.fixed }

3. Compute gap = max(0, c.bill × clinicFloorPct − c.recovery) for each IN clinic
   not yet fixed.

4. Find the IN clinic with the LARGEST positive gap. If none (all IN clinics are
   at or above floor, or there are none), DONE — current recoveries are final.

5. Raise that clinic to its floor:
       targetRecovery = c.bill × clinicFloorPct
       availableForRaise = netAvailable − sum(c2.recovery for c2 fixed) − sum(c3.recovery for c3 not fixed except this one)
       (Equivalently: pool currently allocated to non-fixed-others is what we
        can pull from. Math hint: the pool we "take from" is the sum of recoveries
        of the non-fixed clinics other than the one being raised.)

   If the pool can cover the raise: set c.recovery = targetRecovery,
                                    set c.floorApplied = true,
                                    set c.fixed = true.
   If the pool can't cover the raise: set c.recovery = whatever pool remains for it
                                       (i.e. raise to the maximum the remaining pool
                                       allows), mark fixed and floorApplied,
                                       set every other not-fixed clinic to 0,
                                       mark them all fixed,
                                       set poolExhausted = true.
                                       RETURN.

6. Re-pro-rata across the remaining (non-fixed) clinics:
       remainingPool = netAvailable − sum(c.recovery for c fixed)
       remainingBillsTotal = sum(c.bill for c not fixed)
       for each non-fixed c: c.recovery = (c.bill / remainingBillsTotal) × remainingPool

7. Goto step 2.
```

**Convergence:** each iteration either fixes one IN clinic (one fewer to consider) or exhausts the pool. Bounded by N where N = count of IN clinics on the case.

**Helpful invariants for testing:**
- `sum(recoveries) === netAvailable` always (modulo floating-point — round to cents at display).
- A non-IN clinic's `floorApplied` is always `false`.
- An IN clinic's `recovery >= bill × clinicFloorPct` UNLESS `poolExhausted === true`.

## Floor rounding

`bill × 0.20` may produce sub-cent values (e.g. `$1,567.50 × 0.20 = $313.50`, but `$1,567.55 × 0.20 = $313.51`). Round the floor target **up to nearest cent** so the clinic always meets or exceeds the statutory minimum:

```js
const floor = Math.ceil((c.bill * clinicFloorPct) * 100) / 100;
```

Below the table, replace the existing pro-rata note with this conditional logic:

```js
const floorAppliedCount = clinics.filter(c => c.floorApplied).length;

if (poolExhausted) {
  note = `Pro-rata distribution applied with Indiana 20% clinic floor enforcement. Pool exhausted — some clinics receive less than statutory floor.`;
} else if (floorAppliedCount > 0) {
  note = `Pro-rata distribution applied with Indiana 20% clinic floor enforcement. ${floorAppliedCount} IN clinic(s) raised to floor; remaining net pool re-distributed pro-rata.`;
} else if (netAvailable < totalBills) {
  note = `Pro-rata distribution applied — net pool insufficient to cover all bills in full.`;
} else {
  note = null;  // no note when fully covered
}
```

### Test scenarios (all assume `clinicFloorPct = 0.20`)

**S1 — All non-IN, fully covered.** Two KC clinics, bills $5K + $10K, net $30K. Expect: each gets full bill, patient residual $15K, no `[FLOOR APPLIED]` tags, no note (or pure-pro-rata note suppressed when fully covered).

**S2 — All non-IN, short pool.** Two KC clinics, bills $5K + $10K, net $9K. Expect: pure pro-rata (3K + 6K), no floor tags, existing pro-rata note: `Pro-rata distribution applied — net pool insufficient to cover all bills in full.`

**S3 — One IN clinic, pro-rata above floor.** One IN clinic, bill $10K, net $5K. Pro-rata gives $5K. Floor is `$10K × 0.20 = $2K`. $5K > $2K, so no raise. Expect: recovery $5K, no tag, pure-pro-rata note (since net < bill).

**S4 — One IN clinic, pro-rata below floor.** One IN + one KC clinic, bills IN $10K and KC $10K, net $5K. Pro-rata gives each $2,500. Floor for IN is $2K. $2,500 > $2K, no raise. Expect: pure pro-rata, no tag.

**S5 — One IN clinic, raised to floor.** One IN + one KC clinic, bills IN $5K and KC $15K, net $4K. Pro-rata gives IN $1,000, KC $3,000. Floor for IN is $1,000 — wait that's exactly equal — adjust: bills IN $10K and KC $10K, net $2K. Pro-rata gives each $1,000. Floor for IN is $2,000. Raise IN to $2,000. Re-pro-rata KC across remaining $0. KC = $0. Expect: IN recovery $2,000 with `[FLOOR APPLIED]` tag, KC recovery $0, note: `Pro-rata distribution applied with Indiana 20% clinic floor enforcement. 1 IN clinic(s) raised to floor; remaining net pool re-distributed pro-rata.`

**S6 — Multiple IN clinics, both raised.** Two IN clinics, bills $10K and $5K, net $2K. Pro-rata gives $1,333 and $667. Floors are $2K and $1K. Both below floor — biggest gap is the $10K-bill IN clinic ($2K − $1,333 = $667 gap vs. $1K − $667 = $333 gap). Raise the $10K-bill IN to $2K. Remaining pool is $0 for the second IN. Floor needs $1K but pool is $0. Pool exhausted. Expect: IN $10K recovery $2,000 with `[FLOOR APPLIED]`, IN $5K recovery $0 with `[FLOOR APPLIED]` (it tried and failed), note: `Pro-rata distribution applied with Indiana 20% clinic floor enforcement. Pool exhausted — some clinics receive less than statutory floor.`

If S5 or S6 produce different math than spec'd, the algorithm is wrong — fix before shipping.
